# Architecture map

The system is organized as a sequence of bounded transformations: sources become observations; observations become relationships and candidate patterns; patterns inform opportunities; opportunities inform strategies and experiments; only high-confidence, gate-cleared opportunities may become repository genesis dossiers. Each transformation preserves provenance and may be rejected, deferred, contradicted, or superseded.

The repository-native graph is canonical in v0. JSON Schema defines record contracts. Scripts validate records, detect orphaned edges, generate deterministic indexes, emit JSONL projections, summarize graph predicates, and create content receipts. Notebooks support exploration but cannot create accepted knowledge.

The daily intelligence automation performs intake and preliminary synthesis. The weekly landscape review performs baseline comparison, Socratic descent, actor-behavior analysis, analogue reconstruction, strategic synthesis, and formal genesis gating. Human governance controls acceptance, implementation, spending, outreach, applications, and repository birth.
