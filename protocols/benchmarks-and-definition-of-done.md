# Benchmarks and definition of done

## Pipeline benchmarks

Schema validation must pass for every durable record. Index generation must be deterministic across repeated runs on unchanged inputs. Every relationship endpoint must resolve or be reported as an orphan. Every pattern must cite at least two observations. Every opportunity must include two actor classes and explicit counterevidence or missing evidence. Every genesis dossier must pass all fatal gates, include three analogue classes, identify a falsifier, and score at least 0.82 before it may be presented as approval-ready.

## Review benchmarks

Weekly output must compare the current seven-day window with a four-week baseline, report source coverage and collection failures, distinguish facts from inference, include at least one weakened or rejected interpretation when evidence warrants it, and produce no more than three strategies, two experiments, and one genesis candidate.

## Operational benchmarks

A no-change week must produce a receipt rather than invented novelty. Re-running the same input set must produce identical indexes and hashes. A removed source must create an explicit provenance warning. A contradiction must become a graph relationship rather than silently replacing a prior claim. Accepted knowledge must always show the approval event.

## Definition of done for v0

The v0 slice is done when the repository contains validated schemas, a deterministic validator and index builder, orphan detection, receipt generation, actor and relationship mapping, weekly and Socratic protocols, a notebook boundary, sample fixtures for pass, reject, and defer cases, and CI commands that fail on malformed records. The daily intelligence automation must emit records compatible with the run schema and must never accept knowledge or create repositories automatically.

## Definition of done for an opportunity

An opportunity is review-ready when its sources resolve, facts and inferences are separate, actor behavior is visible, evidence dimensions are populated, counterevidence is represented, confidence is justified, and its disposition can be independently reproduced.

## Definition of done for genesis

A genesis candidate is approval-ready only when the existing-repository test has failed for principled reasons, the dangerous assumption has a bounded experiment, analogue lessons are explicit, fatal gates are clear, kill criteria are recorded, and the proposed first repository milestone is measurable and reversible.
